The noisy gradient balls
on variantly.style

A smooth 3D shaded sphere, then one full-screen post pass that adds film grain, stipples the edges and paints a grainy halo. Four steps:

01

Shade a blob

Icosphere, vertices pushed out by 3D value noise. Diffuse + specular + rim light is the gradient.

p = position + normal * n(normal*1.6 + t)*.45; col = c*dif + spec + rim;
02

Grain, by luminance

Copy the frame to a texture, redraw it. Two hashes summed = film-like noise, strongest in midtones.

w = .5 + 2.*l*(1.-l); n = hash(p,1u)+hash(p,2u)-1.; rgb += amt * w * (n + chroma*ch);
03

Stipple the edges

Dither alpha with the same noise where the edge fades. Soft edges break into dots, like print.

edge = 4.*a*(1.-a); a += 2.5*amt*edge*(hash(p,6u)-.5);
04

Grainy halo

12 blur taps on a golden-angle spiral, turned by a random angle per pixel. The blur is grainy by design.

a = turn + i * 2.3999632; r = R * sqrt((i + jitter) / 12.); glow += tex(uv + r*vec2(cos a, sin a));
Use a PCG hashfract(sin(dot())) drew repeating diagonal worms on some GPUs. An integer hash never tiles.
No clock in the noiseKeyed to pixels only, so the grain never shimmers while the balls drift.
Phones get SVGShapes drawn twice, filled with a grain PNG tile at two sizes, one turned 37°. No WebGL, no filters.
