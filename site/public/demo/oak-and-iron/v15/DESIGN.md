# Oak & Iron: Weekend feature spread

A weekend-supplement interiors feature, in the style of today's editorial serif revival: a high-contrast Didone set very large, cut against a heavy grotesk for every label and control.

## Colour
One ink, printed on newsprint white. Every mark is that ink, at full strength or knocked back.
- `--paper` #f7f3ec · `--ink` #5a1418 (oxblood) · `--ink-2` #6e2a2d for secondary text · `--tint` #ecdfd6 for plates
- Dark: bone ink (#f1d9d2) on #1c1213.

## Type
- Display: Bodoni Moda, set from 3rem up to 7.5rem, tracking -0.04em, italic for the ampersand.
- Text: Newsreader at 1.1875rem/1.6, set in three columns with a drop cap.
- Labels, nav and buttons: Schibsted Grotesk 500/800, uppercase, letter-spaced.

## Layout
A folio line, a headline that spans the full measure, a standfirst, then a three-column feature with a pull quote between double rules. Products sit in a three-up grid of ink line drawings on tinted plates. The testimonial is set as a full-width italic pull quote. Sections are divided by hairline rules, never boxes.

## Components
Buttons are solid ink rectangles that turn to outline on hover. Inputs are a single underline. The focus ring is a 2px ink outline.
