# Workshop Desktop

An early desktop OS, re-typeset for 2026. The shop is a set of windows on a dotted glacial-teal desktop: striped oxblood title bars, close/zoom boxes, 2px charcoal outlines, pixel icons drawn on a 12px grid.

- **Type:** Bricolage Grotesque (display 800, tight tracking; body 400), JetBrains Mono only for paths, prices and status data.
- **Colour:** desktop #cfdcd9 with #a9bfbb dither dots; window warm ivory #fbf6ec; ink charcoal #24211f; title bars oxblood #7a2430; icons burnt sienna #a4471f and muted teal #2f6b6a. Dark theme via `html[data-theme=dark]`.
- **Components:** `.win` (bar + pane), pixel product plates (`.art`, crispEdges SVG, sienna wood / charcoal iron), double-ring buttons, Get Info list for features, alert-dialog newsletter, status-bar footer.
- **Motion (the one digital effect):** windows zoom open from their centre with a dotted ghost outline, staggered, like an early Finder. Off under reduced motion.
- **Phone:** bands become windows on the desktop; title-bar text sits in the kicker/label.
