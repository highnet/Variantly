# Northgate Cycles (example)

A fictional bike repair shop whose site is a stock Bootstrap-era template:
a blue navbar, a grey jumbotron, three equal cards with icon circles, a
striped price table, a blue contact form and a dark footer. Nothing is wrong
with it; it just looks like every other small-business site. It is the
"before" on the site's How it works page.

Try it without an agent:

```sh
cp -r examples/northgate-cycles /tmp/northgate && cd /tmp/northgate
git init -q && git add -A && git commit -qm "before"
npx variantly --demo
```
