# Oak & Iron (example)

A fictional furniture shop whose site works and looks like every AI-generated
landing page: a purple-to-cyan halo on a grid background, gradient text, glass
cards, a pill badge over an oversized headline, hero metrics, pulsing dots,
emoji icon tiles and Inter everywhere. It is variantly's standard "before",
used in the docs, the tests and the trailer.

Try it without an agent:

```sh
cp -r examples/oak-and-iron /tmp/oak && cd /tmp/oak
git init -q && git add -A && git commit -qm "before"
npx variantly --demo
```
