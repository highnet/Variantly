# Oak & Iron (example)

A fictional furniture shop whose site works and looks like every other
template: a blue-to-purple gradient hero, round red buttons, emoji icons, Arial
and drop-shadowed cards. It is variantly's standard "before", used in the docs,
the tests and the trailer.

Try it without an agent:

```sh
cp -r examples/oak-and-iron /tmp/oak && cd /tmp/oak
git init -q && git add -A && git commit -qm "before"
npx variantly --demo
```
