# Oak & Iron (example)

A fictional furniture shop whose site looks like a 2021 marketplace theme
that someone later ran through an AI: a purple-to-blue hero over a blurry
stock photo, Montserrat caps, a wave divider, hero metrics, ribbons and five
stars, a testimonial carousel, "As seen on" logos, a cookie banner, a chat
bubble, and AI copy with emoji throughout. It is variantly's standard
"before", used in the docs, the tests and the trailer.

Try it without an agent:

```sh
cp -r examples/oak-and-iron /tmp/oak && cd /tmp/oak
git init -q && git add -A && git commit -qm "before"
npx variantly --demo
```
